# Telegram-бот для заявок «Низкий профиль»

Бот делает две вещи:

1. **Принимает заявки с сайта** — когда клиент заполняет форму записи, заявка
   мгновенно приходит вам в Telegram.
2. **Позволяет клиенту отслеживать запись** — клиент получает короткий код и пишет
   его боту, чтобы узнать статус.

Сервер один: он одновременно отдаёт сайт, принимает заявки и крутит бота.

---

## Что уже сделано в проекте

- `server/app.py` — веб-сервер (отдаёт сайт + принимает заявки).
- `server/bot.py` — Telegram-бот.
- `server/store.py` — хранение заявок в файле `server/bookings.json`.
- `server/config.py` — настройки (читаются из `.env`).
- `script.js` — форма на сайте теперь отправляет заявку на сервер (раньше открывала WhatsApp).
- `requirements.txt` — список библиотек Python.
- `start.bat` — запуск в один клик (Windows).

---

## Шаг 1. Создать бота и получить токен

1. В Telegram откройте **@BotFather**.
2. Отправьте команду `/newbot`.
3. Придумайте имя и **username** (должен заканчиваться на `bot`, например `nizkiyprofil_bot`).
4. BotFather пришлёт **токен** вида `123456789:AAH...` — скопируйте его.

## Шаг 2. Заполнить файл .env

1. Скопируйте файл `.env.example` и назовите копию `.env`.
2. Откройте `.env` в Блокноте и заполните:

```
BOT_TOKEN=сюда_токен_от_BotFather
BOT_USERNAME=nizkiyprofil_bot
OWNER_CHAT_ID=
PORT=5000
```

`OWNER_CHAT_ID` пока оставьте пустым — заполним на шаге 4.

## Шаг 3. Запустить сервер

Дважды кликните по файлу **`start.bat`**.
При первом запуске он сам поставит всё необходимое (1–2 минуты), затем запустит сервер.

Когда увидите строку `Сайт и API: http://localhost:5000` — всё работает.
Откройте в браузере `http://localhost:5000`.

> Важно: сайт нужно открывать именно через `http://localhost:5000`,
> а не двойным кликом по `index.html` — иначе форма не достучится до сервера.

## Шаг 4. Узнать свой chat_id и получать заявки

1. Найдите своего бота в Telegram (по username из шага 1) и нажмите **Start**.
2. Отправьте боту команду `/id` — он пришлёт ваш `chat_id` (число).
3. Впишите это число в `.env` в строку `OWNER_CHAT_ID=...`.
4. Перезапустите `start.bat`.

Теперь все заявки с сайта будут приходить вам в Telegram.
Если хотите получать заявки на несколько аккаунтов — впишите ID через запятую:
`OWNER_CHAT_ID=111111111,222222222`.

## Шаг 5. Проверить

1. Откройте сайт `http://localhost:5000`, нажмите «Записаться», заполните форму.
2. Заявка придёт вам в Telegram, а клиенту на сайте покажется его **код** и ссылка на бота.
3. Клиент открывает бота, отправляет код — видит статус заявки.

## Как клиент отслеживает запись

- После отправки формы на сайте появляется код (например `K7QF2`) и ссылка
  «Отслеживать статус в Telegram».
- Клиент пишет боту этот код и получает текущий статус.
- Потерял код — жмёт кнопку **«📱 Моя заявка по номеру»**: Telegram подтверждает,
  что номер принадлежит именно ему, и бот показывает его заявку.
- Номер, написанный текстом, бот намеренно игнорирует — иначе чужую заявку мог бы
  посмотреть любой, кто знает номер клиента.
- Владельцу можно переслать боту контакт клиента — придёт карточка его заявки.

## Меню владельца (кнопки)

После `/start` владельцу показывается меню:

| Кнопка | Что делает |
|--------|------------|
| **➕ Новая запись** | Внести клиента вручную (звонок / с улицы): имя → телефон → услуга → визит |
| **📋 Заявки** | Последние 10 записей |
| **📅 Назначить визит** | Выбрать заявку и поставить дату/время после созвона |
| **❌ Отменить** | Отменить выбранную заявку |
| **🏠 Меню** | Показать подсказки снова |

Под каждой заявкой также есть кнопки:
**📞 Позвонить · 📅 Визит · ✅ Подтвердить · 🔧 В работу · 🏁 Готово · ❌ Отменить**.

Когда визит назначен, за **5 часов** до него система готовит напоминание клиенту.
SMS пока не подключено: в консоль пишется текст, вам в Telegram приходит копия.
Позже достаточно добавить `SMS_API_ID` и дописать отправку в `server/reminders.py`.

Команда `/list` — то же, что кнопка «Заявки».

## Защита от спама (множественных заявок)

Встроено несколько уровней защиты (без сторонних сервисов):

- **Лимит по номеру телефона и IP:** не чаще 1 заявки в 5 минут и не больше 5 в сутки.
- **Анти-бот:** скрытое поле-ловушка (honeypot) и проверка, что форму не отправили мгновенно.
- **Кулдаун в браузере:** после отправки форма временно блокируется на 5 минут.

Значения можно изменить в файле `server/app.py` вверху:

```
ANTIBOT_MIN_MS = 1500   # минимальное время заполнения формы, мс
RL_MIN_INTERVAL = 300   # интервал между заявками, секунд (300 = 5 мин)
RL_DAILY_MAX = 5        # максимум заявок в сутки с номера/IP
```

После изменения — перезапустите сервер.

## Где это разместить, чтобы работало постоянно

Пока сервер запущен на вашем компьютере, всё работает только когда компьютер включён
и только для теста. Чтобы заявки принимались всегда, сервер нужно разместить онлайн.
Простой бесплатный вариант:

### Вариант для новичка — Render.com (бесплатно)

1. Зарегистрируйтесь на https://render.com
2. Загрузите проект на GitHub (или используйте «Deploy from Git»).
3. Создайте **Web Service**, укажите:
   - **Build command:** `pip install -r requirements.txt`
   - **Start command:** `python server/app.py`
   - В разделе **Environment** добавьте переменные `BOT_TOKEN`, `BOT_USERNAME`, `OWNER_CHAT_ID`.
4. После деплоя Render даст адрес вида `https://nizkiy-profil.onrender.com` — это и есть ваш сайт.

> На бесплатном тарифе Render сервис может «засыпать» при простое — первая заявка
> после паузы придёт с задержкой в несколько секунд. Для постоянной работы возьмите
> платный тариф (от пары долларов) или небольшой VPS.

### Российский VPS (рекомендуется, ~350–550 ₽/мес)

Пошаговая инструкция: **`ИНСТРУКЦИЯ-VPS.md`**.  
Быстрый старт с Windows: запустите **`deploy-vps.bat`**.

### Если есть свой сервер/VPS (вручную)

Установите Python 3, скопируйте проект, выполните
`pip install -r requirements.txt`, заполните `.env` и запустите
`python server/app.py` (лучше через systemd или `pm2`, чтобы работал постоянно).

Проще — через Docker: см. `ИНСТРУКЦИЯ-VPS.md`.

## Частые вопросы

**Заявки не приходят в Telegram.**
Проверьте, что в `.env` заполнены `BOT_TOKEN` и `OWNER_CHAT_ID`, и что вы нажали
Start у бота. Команда `/id` должна отвечать вашим числом.

**Форма на сайте пишет «Не удалось отправить».**
Сайт открыт не через сервер. Откройте `http://localhost:5000`, а не файл напрямую.

**Где хранятся заявки.**
В файле `server/bookings.json`. Его не нужно публиковать (он уже в `.gitignore`).
